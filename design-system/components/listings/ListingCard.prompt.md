The product's hero object. `vertical` in feeds and grids, `horizontal` in saved/search lists.

```jsx
<ListingCard image={photo} title="Chambre lumineuse — Agdal" district="Agdal" city="Rabat"
  price="3 200" flatmates="2 colocataires" rating="4,8" badge="Nouveau" />
<ListingCard layout="horizontal" title="Studio Gauthier" city="Casablanca" price="5 400" />
```
Prices always use a thin space thousands separator and read `MAD/mois`.
