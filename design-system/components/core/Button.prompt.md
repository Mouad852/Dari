The one action control — pill radius, 44px default height, terracotta primary.

```jsx
<Button iconLeft="message-circle">Contacter</Button>
<Button variant="secondary" size="sm">Enregistrer</Button>
<Button variant="ghost" iconRight="chevron-right">Voir tout</Button>
```

Rules: one primary per view; full-width primary inside mobile sheets (`fullWidth`); never square the corners.
